🌍 CycleX

Recycling Made Simple - Connect, Collect, Earn

📱 What is CycleX?

CycleX is a comprehensive recycling management platform that connects customers who want to sell recyclable items with collectors who pick them up. Built on Odoo 18, it provides a complete ecosystem for managing the entire recycling workflow from request creation to payment processing.

✨ Key Features

📱

Mobile First

Native iOS (Swift) and Android (Kotlin) apps for customers and collectors

💰

Wallet System

Automatic earnings tracking and withdrawal management with configurable thresholds

📞

SMS Verification

Secure phone-based authentication using SMS Misr gateway

🔔

Push Notifications

Real-time updates via Firebase Cloud Messaging

📷

QR Code Verification

Secure order confirmation through QR code scanning

🌐

Multilingual

Full support for Arabic and English languages

📍

GPS Tracking

Automatic location detection for pickup requests

⭐

Rating System

Customer feedback and collector performance tracking

🔄 Customer Workflow

1
Register with phone number and verify via SMS
2
Browse categories and select recyclable items
3
Create request with quantity, weight, and photos
4
Set pickup date and location (auto-detected)
5
Wait for collector acceptance and pickup
6
Collector scans QR code and confirms payment
7
Wallet credited automatically - rate and review

🚚 Collector Workflow

1
Register with ID, vehicle type, and working areas
2
Wait for admin approval
3
View available orders in assigned regions
4
Accept orders (3-day completion deadline)
5
Navigate to customer location
6
Scan customer QR code to verify order
7
Complete order and earn commission

🛠 Technical Stack

Odoo 18 Python 3.10+ iOS (Swift) Android (Kotlin) Firebase FCM SMS Misr API QR Code GPS/Location REST API

💼 Revenue Model

CycleX operates on a commission-based model where the platform earns a percentage of each completed transaction. Collectors also earn commissions for their services, creating a win-win ecosystem for all participants.

  • Platform Revenue: Commission on each transaction
  • Collector Earnings: Configurable commission per order
  • Customer Benefits: Easy way to monetize recyclables
